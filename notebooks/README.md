# Notebooks

Notebook folders are organized by role:

- `reproduction/`: notebooks used to reproduce data generation, tables, and figures from the paper workflow.
- `method_development/`: notebooks used to inspect, rerun, or modify deconvolution methods.
- `exploratory/`: ad hoc simulations and exploratory analyses.

Large notebook input data is stored under `data/example_notebooks/`. Notebooks that need those files should reference that canonical data location rather than keeping a duplicate copy under `notebooks/`.
