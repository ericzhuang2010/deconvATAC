Although most cells in an organism contain nearly the same DNA, different types of cells use different parts of that DNA. One reason is that different regions of DNA are accessible in different cell types. Spatial ATAC-seq is a method that identifies accessible regions of DNA
ATAC-seq is a method used to measure areas of chromatin accessibility. It uses information about where different accessibility patterns are found within a spot. However, a spot can contain multiple different types of cells. To address this, the problem of deconvolution seeks to identify the concentration of each type of cell. Current methods for deconvolution generally use ATAC peak counts, based on the locations of the fragments. However, there is other information in addition to the locations that can be considered. I therefore want to test whether using both peak accessibility and fragment length can improve the accuracy of spatial ATAC-seq deconvolution compared with using peak counts alone.
My method, known as ShapeMix-ATAC, would use both peak accessibility and fragment length by sorting fragment length into three bins based on the number of base pairs. I will train a model based on a public PBMC dataset, which will provide the necessary data. I will separate the cells into reference and test groups and simulate spatial spots, and the method would estimate the proportions of the different cell types. There will be two versions of the general model, one which contains fragment length information, and another which combines it into total peak counts. The central experiment would be whether the first version is more accurate than the second.




Almost every cell in your body carries the same DNA, yet a neuron and an immune cell behave completely differently. A big reason is chromatin accessibility: each cell type opens up different regions of its DNA for use. ATAC-seq is the standard method for measuring accessibility, and a new technology called spatial ATAC-seq measures it across an intact tissue slice, showing where regulatory programs are active. Since it was introduced in Nature in 2022, it has already been widely used to study brain development, tumors, and Alzheimer's disease.

But there's a catch. Spatial ATAC-seq doesn't measure single cells — it measures spots, and one spot can contain many cell types mixed together. Interpreting the data requires deconvolution, which estimate what fraction of each spot comes from each cell type. 

This is still an open problem. No deconvolution method has been invented specifically for spatial ATAC. The state of the art — a 2025 benchmark — simply borrows methods designed for spatial RNA data. Those methods only count fragments in each peak, and that throws away signals (features) unique to ATAC. Because DNA wraps around nucleosomes, ATAC fragments come in different sizes: short fragments from open, nucleosome-free DNA, and longer ones spanning one or two nucleosomes. RNA data has nothing like this.

My method, ShapeMix-ATAC, keeps that signal by splitting each peak's counts into three fragment-length bins. Using a public blood-cell dataset, I'll simulate spatial spots with known cell-type mixtures and compare two versions of the same model — one with length bins, one with counts collapsed. If fragment length helps, it would improve accuracy for every study built on spatial ATAC data, has a huge impact in this area due to the wide use of Spatial ATAC sequencing.
