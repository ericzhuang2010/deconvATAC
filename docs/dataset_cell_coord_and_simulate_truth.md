# Cell Coordinates and Simulation Truth

## Core Point

Ground truth for these benchmark datasets comes from knowing which source cells were used to create each spatial spot.

The key requirement is:

```text
source cell -> cell type label
source cell -> ATAC profile
```

Cell coordinates are useful, but they are not always required.

## Case 1: Source Cells Have Coordinates

This is the Russell case.

Russell reference:

```text
data/raw/references/russell_250/atac/reference.h5ad
```

The reference contains:

```text
obs["cell_type"]
obsm["spatial"]
```

That means each source cell has:

```text
cell_id
cell_type
ATAC profile
x, y coordinate
```

The `russell_250` spatial dataset can therefore be generated by coordinate binning:

1. Divide the coordinate plane into windows.
2. Find all source cells inside each window.
3. Sum their ATAC profiles to create one spatial spot.
4. Compute ground-truth cell-type proportions from the grouped source cells.

Example:

```text
spot_0 contains 10 source cells:
  5 tumour_1
  3 tumour_2
  2 T_CD8
```

Truth:

```text
tumour_1: 0.5
tumour_2: 0.3
T_CD8: 0.2
```

For this case, the simulation provenance can be reconstructed exactly:

```text
data/processed/datasets/russell_250/simulation/source_cells_by_spot.jsonl
```

Each row should record which source cells were grouped into each spatial bin.

## Case 2: Source Cells Do Not Have Coordinates

This is the Heart simulation case.

Heart references:

```text
data/raw/references/human_cardiac_niches/atac/reference.h5ad
data/raw/references/human_cardiac_niches/rna/reference.h5ad
```

The source cells have cell-type labels and molecular profiles, but they do not provide original per-cell spatial coordinates for the simulation.

So the simulation creates artificial spatial structure:

1. Create a synthetic grid of spatial spots.
2. Assign each spot to an artificial region.
3. Choose which cell types are allowed in that region.
4. Randomly sample source cells from those allowed cell types.
5. Sum their ATAC and RNA profiles to create the spatial spot.
6. Compute ground-truth proportions from the sampled source cell labels.

Example:

```text
spot_0 samples 6 source cells:
  3 Mural cell
  2 Mesothelial cell
  1 Mast cell
```

Truth:

```text
Mural cell: 0.5
Mesothelial cell: 0.333
Mast cell: 0.167
```

The provenance is stored as:

```text
data/processed/datasets/<heart_dataset_id>/simulation/source_cells_by_spot.jsonl
```

## Practical Difference

Russell preserves geometry from source-cell coordinates.

Heart creates synthetic geometry because source-cell coordinates are not available.

Both can have valid benchmark truth because both know which source cells created each spot.

## What Real Spatial ATAC Adds

Real spatial ATAC data is useful for external validation, but it usually does not provide exact ground-truth cell-type proportions.

If we only have real spatial ATAC spots, we can run deconvolution and inspect predicted spatial patterns, but we usually cannot compute exact RMSE or JSD against truth.

For quantitative benchmarking, the strongest inputs are annotated single-cell or single-nucleus ATAC or multiome datasets, because we can simulate spots from labeled source cells and know the true mixture by construction.
